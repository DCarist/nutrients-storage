# Nutrients Storage

I've always wanted a mod that modifies the nutrient loop and provides more options than the base game. Nutrients Storage does this. It adds new items, recipes, and technologies to enable longer term storage of nutrients, while hopefully maintaining a bit of balance with the base game.

## How it works.

Technologies are added for Gleba, Fulgora, Aquilo, and end game that enable 20 nutrients to be compacted and stored into nutrient bottles. These bottles are manufactured primarily on gleba requiring steel, plastic, and carbon fiber. Biolabs consume these bottles the same as they would a nutrient, however, a waste product is output after consumption that must be dealt with. Dirty bottles are generated post consumption that can be disposed of (however you would like to approach that problem), or cleaned, with 3 tiers of cleaning available (two immediately with 50% / 75% returns, and one late game that is lossless). As more complicated loops are established you gain better benefits for the bottling process. Base extends nutrient life to 30 minutes, the second to 1 hour, and finally to 2 hours of freshness avaiable (and better compaction, 75% of nutrients processed are available in the bottle vs 50%).
